# Exact NL2 empirical intake, isolated V1

Python 3.11+, standard library only. Run: `python3 -B -m unittest -v`. For CLI, supply `manifest.json --expected-manifest-sha256 <trusted digest> --source <corpus file>`. The out-of-band digest must come from a trusted custody record. Standalone validation does **not** authenticate supplier claims, deduplicate/re-aggregate the source histories, certify an exact solve, or attach locks automatically. The synthetic fixtures always return SYNTHETIC_TEST_ONLY, even with the testing flag.

V1 supports six-max NL2 NLHE cash, two-chip BB/one-chip SB, no antes, two players on flop and supported preflop action families. Each prior street is a full action sequence; bets/raises/calls are exact commitment-to-chip amounts, check/fold is zero postflop (preflop fold preserves previously posted/contributed chips). Flop is three lexically sorted case-sensitive card IDs; turn/river retain chronological order. V1 rejects preflop all-ins/short calls, one player already all-in at the current lock node, and all unrecognized formats rather than broadening scope. Current actions must not already terminate the street. Pot includes all chips contributed up to the exact node; SPR is min(remaining)/pot. Every eligible action must have an explicitly reported count including zero if applicable; rows below n=500 fail. The menu represents the frozen sampled action menu, not all theoretical bet sizes; exclusion of any unavailable empirical actions must be audited independently before integrating.

A trusted parser/reaggregation and exact cohort/replay verification are next gates, not part of this utility. Neither supported schema nor a successful validator result proves observed private hands, sampling independence, provenance lawfulness, or corpus row counts. Out-of-scope or underpowered/missing data should remain unlocked.
